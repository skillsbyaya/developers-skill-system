# Interface copy

Wording written into a specification is built exactly as written, so it is chosen here once and carried everywhere. The default is no explanatory text: a label, a question and its options, or one line of state. A project's own copy rules take precedence where they are stricter.

## Before writing a string

Ask what the user cannot act on without it. If the heading, label, options or the state of the page already say it, write nothing. If something is needed, write the shortest complete version: one purpose, normally one sentence, often a fragment.

## Cut on sight

- **A lead that previews the choices.** “Choose where you sell: to wholesale customers, through your own outlets, or both.” above three options that say the same. Ask the question; let the options answer it.
- **Option descriptions that restate the label.** Under an option, say only what differs between the options and matters to the choice (“Invoiced.” / “Not invoiced.”), or nothing.
- **Why an empty state is empty.** “No channels are set up yet, so there are no figures to show.” Say what is missing and the next action, if there is one: “No channels yet.” “Add one in Settings → Channels.”
- **How the system works.** “Everything belongs to a channel, so these pages stay empty until your first one exists.” Users need what to do, not the model behind it, the rationale or the implementation.
- **An all-clear about something that cannot exist yet.** “Every export is up to date.” before anything has been exported. When a section has nothing real to report and the page already gives the next step, the section is not shown.
- **Reassurance and narration.** “Don't worry, you can change this later.”, “This lets you…”, “Here you can…”. Keep a consequence only when it changes the decision, prevents a plausible mistake, protects access or data, or enables recovery, and put it where that decision is made.

## Longer is right only when

An error, confirmation of a hard-to-reverse action, or recovery state needs what failed or what will happen, and how to recover. Its length is set by that consequence, never by a wish to explain.
